# Changelog

## 0.1.0 — 2026-10-06

Initial developer release: native MLX Swift text, image and audio embeddings;
strict model loading; normalized128/256/512/768-dimensional outputs; actor API;
CLI and physical-iOS validation example. Standard affine8-bit text/vision
weights selected by frozen development checks. BF16 audio is optional.
Includes source provenance, licenses, reproducible references and limitations.
